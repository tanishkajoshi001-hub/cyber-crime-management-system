# 🛡️ Cyber Crime Management System

## 📌 Project Statement

Cyber crime cases require proper handling of case information, evidence, investigators, and investigation status. When this information is managed manually, it can become difficult to organize, update, and track.

The **Cyber Crime Management System** is a Java-based console application developed to provide a simple and organized way to manage cyber crime cases. It allows users to register cases, search records, manage evidence, assign investigators, update case status, and monitor the priority and risk level of cases.

The system also provides **critical case identification** and **case statistics with an ASCII-based graph**, helping users get a quick overview of ongoing cases.

## 👥 Main Users

The system is intended for:

* 👮 **Cyber Crime Investigators** – to manage assigned cases and evidence.
* 🧑‍💼 **Case Administrators** – to register cases, update information, and assign investigators.
* 🏢 **Cyber Crime Departments** – to maintain records and monitor overall case activity.

## ✨ Core Features

* 📁 Case registration and management
* 🔎 Case searching and viewing
* 🧾 Evidence management
* 👮 Investigator management and assignment
* 🔄 Case status updates
* 🚨 Case priority classification
* 📊 Rule-based risk scoring
* ⚠️ Critical case identification
* 📈 Case statistics and ASCII visualization
* 💾 File-based data storage

## 🛠️ Technology

The project is developed using **Java** and demonstrates practical use of:

* ☕ Object-Oriented Programming
* 🧩 Inheritance and Encapsulation
* 📚 ArrayList and Collections
* 💾 File Handling
* 💻 Console-Based Input and Output

## 🎯 Objective

The objective of this project is to create a simple, practical, and easy-to-use system for managing cyber crime cases while applying fundamental Java programming concepts to a real-world problem.

> 🔐 **Organize cases. Track investigations. Manage information efficiently.**
